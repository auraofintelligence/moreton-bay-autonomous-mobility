# Moreton Bay Autonomous Mobility

A highly visual public website and practical action guide for building a proposed people-led, region-wide autonomous road and delivery-drone network across Moreton Bay, with 24/7/365 availability as the service target where needs, conditions and approvals allow.

Its central case is the global trajectory, the timing of Moreton Bay's entry and the assets that can compound the region's position: implementation profiles, operating knowledge, infrastructure, skills, ownership, permits, revenue and reinvestment.

> This is an independent public-interest proposal. It is not an operating service or an announced government program.

It is framed as a self-sovereign people’s implementation plan: communities can organise the vision, evidence, local ownership and targeted advocacy without inventing authority or bypassing approvals.

The site keeps verified context, the proposed implementation program, future possibilities and items to be confirmed visibly separate. Road vehicles and delivery drones are separate workstreams because their approvals, risks and operators differ, but they can advance in parallel across multiple corridors and use cases. The proposed transition model invites existing taxi, bus, community-transport, delivery and maintenance operators to shape future ownership, partnership, workforce and local profit participation; no participation is claimed as confirmed.

Current-status research was checked live on **26 August 2026**. Remembered claims and undated summaries are not used as evidence. An official publisher is evidence of provenance, not freshness: the site gives priority to current law, dated decisions and orders, live registers, regulatory filings and current service-status pages, while preserving conflicts and limitations.

## Preview on this laptop

Open PowerShell in this folder and run:

```powershell
py -m http.server 8000
```

Then open <http://localhost:8000> in a browser. Press `Ctrl+C` in PowerShell when finished.

## Check before publishing

```powershell
npm run check
```

The check covers the eight expected pages, unique titles and hero assignments, local links and assets, image alternative text and dimensions, proposal disclosures, and accidental local paths.

## Publishing

The site is designed for GitHub Pages from the `main` branch and repository root. Do not describe it as published until the intended commit has been pushed, GitHub Pages reports a successful build, and anonymous public checks return the expected pages and images.
